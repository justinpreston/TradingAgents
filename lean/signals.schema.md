# LEAN signals manifest v1.0

`lean/signals.json` is generated by `scripts/export_lean_signals.py` from one or more matrix-run `options_overlay.json` files. Rows are review-first: LEAN should only act on rows where `approved` is `true`.

## Top-level object

| Field | Type | Notes |
|---|---|---|
| `schema_version` | string | Always `"1.0"`. |
| `generated_at` | ISO8601 string | Timestamp with timezone. |
| `source_run` | string | Relative matrix run path; comma-separated when merged. |
| `measure_date` | `YYYY-MM-DD` | `snapshot_date` from the overlay. Merged runs must share it. |
| `signals` | array | Signal objects. Only tiers `A`, `B`, `C` are emitted. |

## Signal object

| Field | Type | Notes |
|---|---|---|
| `id` | string | `<TICKER>-<measure_date>`, e.g. `NUE-2026-06-27`. |
| `ticker` | string | Uppercase underlying ticker. |
| `tier` | string | `A`, `B`, or `C` from the overlay; never re-derived here. |
| `classification` | string | Always `PICK`. |
| `underlying_ref_price` | number | Overlay `current_price_usd`. |
| `option.right` | string | Always `call` for long-call workflow. |
| `option.strike` | number | Long leg strike from `legs[0]`. |
| `option.expiry` | date | Long leg expiration from `legs[0]`. |
| `option.target_delta` | number | Overlay target delta, normally `0.55`. |
| `option.occ_symbol` | string | OCC/Polygon option symbol from `legs[0].symbol`. |
| `option.ref_premium_per_share` | number | Broker-style per-share premium from `legs[0].price`. |
| `entry.max_premium_per_share` | number | `ref_premium_per_share × (1 + slippage_pct)`. Default slippage is `0.05`. |
| `entry.size_pct` | number | `policy.json::tier_sizing[tier].starter_pct`. |
| `entry.max_size_pct` | number | `policy.json::tier_sizing[tier].max_pct`. |
| `exits.cons_pt` | number/null | Conservative PT for A/B. Always `null` for tier C. |
| `exits.aggr_pt` | number | Aggressive PT. |
| `exits.rule` | string | Tier mapping below. |
| `exits.stop_loss_premium_pct` | number | Premium stop, default `-0.40`; CLI/policy override may replace it. |
| `exits.time_stop_dte` | integer | Time stop in days to expiry, default `21`; CLI/policy override may replace it. |
| `approved` | boolean | Defaults `false`. `--approve-all` is testing-only; real workflow is manual approval. |
| `notes` | string | Liquidity and earnings warnings concatenated with `; `, else empty. |

## Canonical exit rule mapping

| Tier | `exits.rule` |
|---|---|
| A | `tier_a_take_profit` |
| B | `tier_b_run` |
| C | `tier_c_trim` |

Non-picks (`VETO`, `—`, missing tier) are skipped.
